# Overport Galaxy XR 0.3.1

Visible application icon on Windows.

- The window and taskbar icon is now the full application icon (white lightning on black).
  The previous window icon was a white glyph on a transparent background, so it disappeared on
  light title bars and taskbars.

Conversion, the Galaxy XR preset, the native adapter and the open dispatcher are unchanged;
APKs converted by 0.3.0 do not need to be reconverted. 0.1.x–0.3.0 users can install this
version from **Updates**.
